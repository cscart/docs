===================
Install as an addon
===================

    The theme is to be installed as an addon, in case the "app" folder is present in theme archive.

    .. fancybox:: img/Install_theme_013.png  
        :alt: App folder

    Open 'Manage Add-ons' Page on the Admin Panel (Admin Panel -> Add-ons -> Manage Add-ons)

    .. fancybox:: img/Install_theme_022.png
        :alt:  Manage add-ons

    Click on a Gear icon and select Manual installation option. 
    
    .. fancybox:: img/Install_theme_021.png
        :alt: Manual Installation

    Click on the Local option and the theme archive to upload.

    .. fancybox:: img/Install_theme_019.png
        :alt: Upload archive

    Click Upload & Install button and observe the installed add-on of theme.

    .. fancybox:: img/Install_theme_020.png
        :alt: Theme add-on

    Install and actvate the rest of the add-ons from the pack

    .. fancybox:: img/Install_theme_018.png
        :alt: Theme pack

    Open the Theme setting page (Admin Page -> Design -> Themes)

    .. fancybox:: img/Install_theme_023.png
        :alt: Theme page

    Open 'Browse all available themes' tab and install theme

    .. fancybox:: img/Install_theme_024.png
        :alt: Install theme

    Once the theme is installed, activate one of the offered styles.

    .. fancybox:: img/Install_theme_025.png
        :alt: Styles box

    Click the Activate button and select the settings to be overwritten by the new theme.

    .. fancybox:: img/Install_theme_026.png
        :alt: Overwrite settings

==================
Install as a theme
==================

    .. note::
        The following instruction is relevant for add-ons that don't require additional installation of the theme as an add-on.

    Open Themes settings page on the Admin Panel and click the Plus button.

    .. fancybox:: img/Install_theme_027.png
        :alt: Theme page

    Make sure that the add-ons included to the pack are installed and activated

    .. fancybox:: img/Install_theme_018.png
        :alt: Theme pack

    Click on the Local option and the theme archive to upload.

    .. fancybox:: img/Install_theme_015.png
        :alt: Upload theme

    Open 'Browse all available themes' tab and install theme
    
    .. fancybox:: img/Install_theme_016.png
        :alt: Install theme 

    Once the theme is installed, activate one of the offered styles.

    .. fancybox:: img/Install_theme_017.png
        :alt: Style box

    Click the Activate button and select the settings to be overwritten by the new theme.

    .. fancybox:: img/Install_theme_028.png
        :alt: Settings Overwrite

============
File manager
============

    You can securely transfer the theme file to the server from your local computer via a software that uses SFTP, SCP, or FTP file protocols. For example, you can use WinSCP for Windows.

    1. Connect to the server where your store is installed via one of the protocols.

    2. Copy the theme file into the **design/ themes/ responsive/ styles/ data** directory.
