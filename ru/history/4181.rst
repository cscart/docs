4.18.1

==================================
Новая функциональность и улучшения
==================================

[+] Панель администратора: Изменен стиль, улучшена навигация, добавлены новые фильтры в список товаров.

[+] Модули: Карты и геолокация: Яндекс: Местоположение продавцов [Beta]: Добавлена настройка ключа API Геосаджеста.

[+] Настройки: Иконки: Добавлена возможность ограничивать размер загружаемых изображений для улучшения производительности.

[+] Модули: PayPal Checkout: Добавлены настройки дополнительных способов оплаты и внешнего вида кнопок.

=========================================
Изменения в существующей функциональности
=========================================

[*] Multi-Vendor: Модули: Общие товары для продавцов: Промоакции: Промоакция на общий товар теперь распространяется на все предложения продавцов.

[*] Модули: Вариации товаров: Улучшена производительность при большом количестве вариаций, когда в модуле включена настройка "Показать все возможные варианты характеристик".

[*] Центр обновлений: Увеличен таймаут на скачивание пакетов с обновлениями. Добавлена возможность изменить это значение через твик.

[*] Ядро: Библиотека aws-sdk-php обновлена до версии 3.297.2 с соответствующими зависимостями.
